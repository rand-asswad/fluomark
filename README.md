# FluoMark

This repository provides the Python module `fluomark` for bioreactor
model state estimation from fluorescence measurements.
The module depends on standard numerical modules: NumPy, Scipy, and Matplotlib.

The repository contains all the source code to reproduce the results
and plots in the article
*Bioreactor state estimation from fluorescence measurements with
unknown resource allocation*
by Rand Asswad and Gildas Besançon.

The [`scripts`](scripts/) directory provides scripts to generate the figures presented
in the article.
